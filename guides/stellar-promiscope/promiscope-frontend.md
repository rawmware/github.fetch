## Heads up

- It's a monorepo (several packages in one). Check the README for which folder to start in.
- Uses better-sqlite3, puppeteer, which can't run inside a browser tab. Use Codespaces instead.

## Or run it on your own computer

```sh

cd promiscope-frontend
npm install
npm run dev
```
