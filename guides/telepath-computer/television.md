## Heads up

- It's a monorepo (several packages in one). Check the README for which folder to start in.
- Uses electron, which can't run inside a browser tab. Use Codespaces instead.

## Or run it on your own computer

```sh
git clone --depth 1 https://github.com/telepath-computer/television.git
cd television
npm install
node packages/cli/dist/cli.cjs
```
