## Commands to type (in Codespaces or StackBlitz terminal)

```sh
pnpm install
pnpm dev:web
```

## Or run it on your own computer

```sh
git clone --depth 1 https://github.com/zai-org/ZCode.git
cd ZCode
pnpm install
pnpm dev:web
```
